# Claudia's Brain

Hosted Page design for every Claudia Grok Bot copy. Download this file; replace only the `LEDGER-DATA` marker block via `claudia_ledger.py build-brain`. Do not redesign the Page.

Raw URL:

```text
https://raw.githubusercontent.com/kbanc85/claudia-grokbot/main/brain/claudia-brain.canvas.tsx
```

The shipped file includes fictional example data (`example: true`) so it renders standalone. The Page shows **Last updated** from the ledger date and an optional **coverage** strip (sources scanned and through what date). Pass `--coverage` or `$CLAUDIA_HOME/work/coverage.json` to `export-brain` / `build-brain`.

Made with Grok Bot.
